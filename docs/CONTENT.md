# Content Policy

MXL Legacy is an archive, so uncertainty must stay visible. Do not add invented quotes, fake screenshots, placeholder image URLs, generic timeline claims, or decorative statistics that look factual.

## Current Sources

The current repository contains profile data and image assets for the MXL Legacy site. Historical expansion should favor seasons, calendars, standings, race videos, driver and team profiles, screenshots, and source notes.

## Adding Content

When adding historical content, include the origin in the relevant data entry or companion docs. Acceptable provenance includes archived league pages, screenshots with context, race videos, Discord exports, public profiles, or direct maintainer notes.
